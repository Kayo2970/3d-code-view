# 3d-code-view

Interactive 3D exploration of the **LEADS ERP** codebase as a knowledge graph.

[graphify](https://github.com/) analysed the ERP repo (221 files · ~466k words of
code + docs) into `graph.json` — **1,857 nodes / 5,220 edges / 237 communities** —
and `viewer/` renders it as a navigable 3D force graph you can open in any browser.

## Contents

| Path | What it is |
|---|---|
| `viewer/` | The 3D viewer (see [`viewer/README.md`](viewer/README.md) for full docs) |
| `graphify-out/` | graphify output: `graph.json`, `graph.html`, `GRAPH_REPORT.md`, per-day snapshots, converted docs |
| `graphify-out/cache/` | AST / semantic build cache — **gitignored**, regenerated by graphify |

## Quick start

Just open the self-contained build — no server, works on phone/tablet/desktop:

```
viewer/graphify-3d-viewer.html
```

It pulls `three.js` + `3d-force-graph` from a CDN on first open, then caches them.

### Live mode (auto-refreshes as the graph changes)

```
cd viewer
python serve.py            # serve + open browser
python serve.py --watch    # also rebuild the shareable HTML on every change
```

Opened this way the viewer reads `graphify-out/graph.json` directly and polls it,
so re-running `graphify update .` refreshes the graph on its own.

## Controls

Drag to orbit · scroll to zoom · click a node to inspect it and highlight its
neighbours · click the background to reset. Layout, colour-by, node-type toggles,
degree filters, and search live in the side panels (☰ / ▤ buttons on mobile).
Full reference in [`viewer/README.md`](viewer/README.md).

## Regenerating

| After... | Run |
|---|---|
| code changes in the ERP repo | `graphify update .` (no API cost) |
| updating the snapshot / shareable file | `cd viewer && python build-data.py` |

Graph freshness: built from ERP commit `2252f4d7` (see `graphify-out/GRAPH_REPORT.md`).
